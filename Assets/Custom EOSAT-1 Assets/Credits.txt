<b>Software and tools</b>
Game engine: Unity 6 (6000.6.2f1), Universal Render Pipeline, Unity Technologies
VR: XR Interaction Toolkit 3.5.1 and OpenXR, with the Unity VR project template's starter assets
Text: TextMesh Pro (included with Unity)
Headset: Meta Quest 2, 3, and Pro
Telemetry: the client's EOSAT-1 simulator and the supplied test stub (vr_stub.py)

<b>AI assistance</b>
Much of the code was written with Claude (Claude Sonnet 5.5, Anthropic) through Claude Code. That covers the warning system, space view, welcome panel, panel builder tools and settings. C.U.B.E.15 directed, tested and approved it.
